Gradio Backend Connection

This custom static front-end connects to the Gradio backend server. The Gradio server exposes a REST API that this page can call to perform inference, download models, and manage settings.

Click the button below to check the Gradio API status. The Gradio API is available at /api/ and supports all the same operations as the built-in Gradio UI.

How to Use

Option 1 – Gradio Built-in UI: Navigate to / to use the full Gradio interface with the custom theme editor.

Option 2 – Custom Front-End: Use this page or build your own front-end that calls the Gradio API endpoints. The API documentation is available at /api/ or /?view=api.

Option 3 – Embed: You can embed the Gradio app in any web page using an iframe or the Gradio JS client library.
